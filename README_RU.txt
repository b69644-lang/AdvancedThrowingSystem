Advanced Throwing System — исходный прототип

Это исходный C#-проект для ScriptHookRDR2 .NET API, а не готовая DLL.
Загруженный ScriptHookRDRNetAPI.xml — документация API, не сама библиотека.
Для компиляции нужна ScriptHookRDRNetAPI.dll из папки игры.

Управление:
E — поднять ближайший предмет или животное из белого списка.
R — бросить в направлении камеры.
G — положить рядом с Артуром.

Сборка:
1. Установи Visual Studio с .NET Framework 4.8 Developer Pack.
2. Открой AdvancedThrowingSystem.csproj.
3. Укажи переменную RDR2_DIR с путём к корневой папке RDR2
   либо исправь HintPath на свой ScriptHookRDRNetAPI.dll.
4. Собери конфигурацию Release.
5. Скопируй bin\Release\net48\AdvancedThrowingSystem.dll в папку RDR2\scripts.

Ограничения:
- XML подтверждает документацию API, но не гарантирует все эффекты в игре.
- Проект не компилировался: загружен XML, но не бинарная DLL API.
- Попадание пока определяется приближённой проверкой расстояния, не физическим callback.
- Для животных используется небольшой список моделей, который может потребовать правки.
- Пока управление клавиатурное; геймпад и точные анимации — следующий этап.
- Тестируй в сюжетном режиме, предварительно сделав резервную копию сохранения.
